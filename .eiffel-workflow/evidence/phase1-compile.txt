## Defects found and fixed during this phase

1. ECF: clusters declared in an EXTENDING target do not inherit the parent
   target's <option> assertions. handoff, facade, and the test cluster first
   ran with every contract unmonitored (TEST_SLOT.empty_frame_refused failed;
   the codec's `decodable' postcondition never fired). Two-target repro in the
   scratchpad confirmed it; fix: repeat <option> in each extending target.
   Recorded as oracle gotcha "Extending ECF target drops assertions".
2. VWOE: `m |=| (old m) & x' parses as `(m |=| old m) & x'. Parenthesized.
   Oracle gotcha "MML free-operator precedence".
3. VD00: library "testing" and cluster "testing" clash; cluster renamed "tests".
4. ec.sh check printed "Syntax and type check passed" over a VWOE error, and an
   incremental check skipped 14 new files after Degree 6. Oracle gotchas
   recorded; every gate above was run from clean EIFGENs and read for
   "Error code".

## Deviations from spec 07 (for /eiffel.review)

- TM_SELF_PROCESS (new, probe): the facade's pid and creation-time externals
  moved here; probe stays the only cluster with externals.
- Clusters are explicit (model, probe, sampling, handoff, facade) instead of
  one recursive src, so simple_taskman_measure can prove the Q7 layering.
- Attribute "require" clauses (user_ticks etc.) are functions over private
  storage; handles belong to the memory group.
- TM_PROCESS_ACTIVITY.make_from_pair contracts are stronger than 05: exact
  CPU and IO rates, invalid when impossible or backward, worse_of reason kept.
- TM_SYSTEM_SOURCE gains support_reason, supported_codes, logical_processors;
  TM_PROCESS_SOURCE gains is_native, samples_model, has_idle_entry.
- TM_FRAME_CODEC: create make (not default_create); decode_capabilities is a
  command with last_capabilities (CQS), plus frame_texts_in for replay files.
- TM_FRAME_SLOT.put_frame: 05's `copy_owned: frame_text.same_string (a_text)'
  cannot compile against a separate argument; replaced by `copied: count equal'.
- TM_SAMPLING_WORKER caps the budget maximum at 60 000 ms so
  set_nominal_interval's precondition always holds.
- TM_SELF_BUDGET contracts reworded so streak reset after back-off does not
  make `backs_off' vacuous; Under_limit = 30 added.
- TM_CPU_TOPOLOGY gains make_from_groups, flat_index, heatmap_rows/columns (R-4).
- Status constant 0xC0000004 written as its signed value (-1073741820).
