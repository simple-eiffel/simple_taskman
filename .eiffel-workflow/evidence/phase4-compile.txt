## Defects found and fixed during implementation

1. ISE compiles C with -D_WIN32_WINNT=0x0500 and -w: newer structs fail
   (C2065 PROCESS_MEMORY_COUNTERS_EX), newer functions compile undeclared.
   Fixed with <external_cflag value="-D_WIN32_WINNT=0x0A00 -DWINVER=0x0A00"/>
   in the ECF, after a scratch repro showed the later definition wins.
   Oracle gotcha "ISE C targets Windows 2000".
2. Lost backslash in four modulo operators (`\` for `\\`) from an edit script;
   caught by reading the bytes, fixed by character code. Edits to Eiffel bodies
   then moved to the Edit tool.
3. Scripted system source stored "not supported" placeholders, which the
   builder's self readings replaced, failing `system_readings_kept`. Sources
   now leave not-supported metrics absent (absent reads exactly that); the
   self.* metrics are never read by a system source.
4. Test design: a wait loop taking the slot as a separate argument held its
   lock for 5 s and starved the replayer. Polling moved to the caller.
   Oracle gotcha "SCOOP: never wait inside a routine that takes the slot".
5. simple_logger keeps its file handle open (upstream W-7), so the logger
   test cannot delete its log; it deletes only before starting.

## Implementation notes for later phases

- Self metrics read "not supported" in the capability report, because the
  system source does not supply them (the frame builder does). The window's
  capability panel should list only hardware metrics.
- Window aggregates cap measured seconds and coverage at the span: frame
  spans follow wall time, durations follow the monotonic clock.
- Sampling with a manual clock that has not advanced violates the builder's
  `ordered` precondition by design; live clocks always advance.
